# MOA Dial

Offline ballistic calculator for iPhone. Enter the rangefinder's distance and height (or angle), get MOA and scope clicks.

Install: open the GitHub Pages link in Safari → Share → Add to Home Screen. Open it once with signal; after that it works offline. Rifle data is stored only on the phone.

In the field: when you reach your hunting spot, tap **Use GPS altitude** under Conditions on the Shot screen (it works with no cell signal), and type the temperature if you know it.

To update: replace the files and bump `VERSION` in `sw.js`.
